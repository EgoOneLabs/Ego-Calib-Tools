# 固定候选参数的独立记录一致性检查

原 Linux key@key 执行：解压 joint-fixed.zip，再运行 `/usr/bin/python3 joint-fixed/run.py`。

本工具针对 2UQ2 的 20261114T075600Z_269e962d 独立录制，以及
joint_camera_updated_hDPklVhP 的候选参数。已有 BAG、IMU 参数及候选外参均逐文件校验。
不重新录制、不覆盖已有结果、不修改容器中的 Kalibr 源码。

## 检查含义

固定相机内参、双目外参、Camera–IMU 外参、每台相机的时间偏移。
只拟合独立记录的运动轨迹、重力方向和 IMU 偏置曲线，然后计算残差。
这是带有上述辅助变量拟合的条件一致性检查，不是完全开环预测，也不证明硬件同步。
必须与独立记录自由求解的残差及两次外参差异一起复核。没有自动通过阈值。

进程内适配器绕过默认的外参旋转先验重估，使用已固定外参初始化姿态和重力。
所有相机的外参及时间设计变量均禁用；优化前后检查变量状态及数值，防止重新求解冒充验证。
依然使用 Kalibr 原有误差项、样条及优化器。原代码版本不匹配会停止。

保留原始计数缺口的时间，不插补 IMU。使用既有实验时间映射和实验噪声权重。
尚未完成厂商时间定义、IMU 内参或最终噪声验收。

## 运行与输出

首次运行可能要求 sudo 密码，保持终端打开。容器任务最多运行 30 分钟；
Ctrl+C 可能只停止等待，不能立即重复启动。工具为验证开发版，尚未在真实 Kalibr 容器中执行验证。
软件单元检查不等于实机验证。

完成后上传 joint_fixed_review.tar.gz。包括 JSON、日志、PDF、TXT 和验证后的 YAML，
不包括大 BAG。失败时也会保留日志和状态供排查。
输出是复核材料，不能自动替换正式标定参数。运行入口尚未集成桌面 App。
