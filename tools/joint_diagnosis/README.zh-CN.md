# 两段已有联合录制的运动与时间记录诊断

在原 Linux 工作站 **key@key** 执行，不需要重新录制、不需要 Docker 或 sudo。
工具只读取两段已确认主板固定后的录制，以及两份联合结果；写入一个新诊断目录，不修改源数据或标定参数。

```bash
cd "$(xdg-user-dir DOWNLOAD)" &&
unzip -oq joint-diagnosis.zip &&
/usr/bin/python3 joint-diagnosis/diagnose.py
```

需要系统 Python 已有 NumPy、PyYAML（原标定工具环境已安装）。

## 检查内容

1. 两份外参中相机中心在 IMU 坐标系内的位移差，避免把变换矩阵平移列与相机中心混为一谈。
2. 全段及分段的计数器—主机包时间拟合；图像接收间隔。它们反映经验时间记录，不是曝光同步精度。
3. 三种分块尺度下的旋转运动与杠杆臂加速度灵敏度。只在连续样本段内求导，不跨缺口插值。

采用刚体点加速度中的线性杠杆臂项 `α × r + ω × (ω × r)`，比较现有两份位置估计的差异会带来多大的该项变化。
忽略相机重投影、轨迹/重力/偏置重拟合、两份旋转和时间偏移的差异；因此它不是完整 Kalibr 可观测性、
参数协方差或质量验收测试。40/100/200 ms 分块是诊断设置，不是官方门限。报告不自动判定通过。

终端会显示结果目录并打开文件夹。请回传 `joint_diagnosis_review.tar.gz`，里面只有小型 JSON/TXT，不包含大 BAG、CSV 或图像。

## 已有报告给出的线索

第二段数据中，固定第一组联合参数，相比自由重算：左右图像平均误差仅增加约 0.0058% / 0.0065%，
陀螺仪约 0.81%，加速度计约 0.12%。在允许拟合轨迹、重力方向及偏置的条件下，这两组参数都能产生很接近的残差。
这支持进一步检查运动约束与参数耦合，不能单凭残差接近就断定平移准确，也不能确认差异来自机械移动。

两小时 IMU 的较新严格分析识别了 6 个白噪声候选和 5 个随机游走候选，缺少陀螺仪 Z 的随机游走候选。
总时长足够并不保证每轴长期噪声都可识别；已有实验混合模型权重继续明确保留实验属性，不自动升级为正式参数。

第一段已上传原始数据的先行诊断：40/100/200 ms 三种分块的方向灵敏度比约 0.916/0.839/0.790，
未呈现明显单轴退化；不能直接将差异归因于“没做三轴运动”。包主机时间拟合残差标准差约 3.19 ms，
它包含传输与请求调度等影响，不是相机–IMU 同步误差。缺少第二段原始 CSV 的当前附件，因此本工具在
原工作站上读取两段完整数据进行对应检查。
