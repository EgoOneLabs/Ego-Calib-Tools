# 硬件与场地准备（Hardware Setup README）

适用于 2UQ2 双目 USB 头环。先确认套件、固定方式和连接，再安装或录制；软件按钮不能弥补松动的装配。

## 1 准备什么（Equipment）

| 物品 | 数量 | 说明 |
|---|---|---|
| 配套左右相机 | 2 个 | 固定在同一头环框架，保持镜头位置稳定 |
| 配套主板 | 1 块 | 当前 IMU 来自此头环设备；不是手机或电脑 IMU |
| 相机排线、框架与固定件 | 按套件 | 使用配套连接方式，不根据软件文档猜接口方向和针脚 |
| 数据线 | 1 根 | 电脑侧接口可匹配电脑；手机侧支持数据与 USB Host / OTG |
| Android 手机 | 手机采集时需要 | Android 12+、arm64 64 位；当前参考手机为华为 STG-AL00 |
| Ubuntu x86_64 桌面电脑 | Linux 标定时需要 | 22.04 / 24.04 为安装支持范围；可联网、使用 sudo，保持供电 |
| AprilGrid 和平整硬板 | 相机/联合标定时需要 | 可用配套大版或 A4 版；静止 IMU 分析不用板 |

不根据 VID:PID 或外观推定其他相机/主板均兼容。当前设备识别参考为 `1bcf:0b15`；主板型号、排线方向、额定供电等未在软件契约中明确的事项，以套件和厂商说明为准。

## 2 装配与固定（Assembly）

1. 断电后安装或调整排线，按套件要求检查接口方向与锁扣。
2. 固定两个相机和主板。握住框架轻轻改变姿态时，各部件不能相对转动、滑动或悬摆。
3. 数据线留出余量并固定，不提拉 USB 线或排线移动设备。
4. 镜头保持清洁。标定板安装平整、光照均匀，避免反光和明显运动模糊。
5. 联合运动采集时握住框架，带动整套头环；不要一手托松动主板、一手移动相机。

胶带重新固定主板可能改变相机–IMU 外参，应重新计算受影响的联合参数。若相机和镜头几何没有改变，相机参数是否可复用需结合实际装配判断，不能只按主板曾移动就认定全部参数失效。

## 3 接到哪里（Connections）

| 任务 | 连接 | 运行程序 |
|---|---|---|
| 日常数据采集 | 头环 → 手机 USB / OTG | 手机 Ego Capture |
| Camera、IMU、Camera–IMU 标定 | 头环 → Linux 电脑 USB | 统一头环标定工具 |
| 已有文件计算 | 文件已在 Linux；不依赖手机采集界面 | 统一工具的已有数据入口；硬件预览取决于本机连接状态 |

同一时间只让一个程序使用设备。充电线、仅提供充电的端口或不支持 Host 的手机，不能替代数据连接。按系统提示允许所需 USB、相机及录音权限；看到连续更新的左右画面后再录制。

## 4 磁盘、供电与场地（Workspace）

Linux 初次安装建议至少预留 30 GiB，供环境下载、合并和导入使用；这是部署建议，不是由硬件规格推导的固定下限。录制和已有数据导入还需额外空间，按页面提示和实际数据量预留。手机会保留原始 Episode 及导出会话，空间占用不只是两路视频。

长时间 IMU 录制时关闭自动休眠，保持供电，放在稳定台面，线缆留松，不触碰或拖动设备。无需强制水平，也没有软件预热等待。建议记录 2～3 小时以观察长期噪声，自定义时长见标定教程。
